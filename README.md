# Arpetal Reisen COCKPIT

Digitale Leitstelle mit:

- Disposition und Anfahrtszeiten
- Konfliktprüfung für Fahrer und Fahrzeuge
- Dauerfahrten mit Wochentagen
- Fahrzeuge und Fahrer
- Urlaubskalender
- einmalige und wöchentlich wiederkehrende Abwesenheiten
- zeitgenaue Sperrzeiten
- Anfragen, Fahrer-App und Auswertung

## GitHub

1. Neues leeres Repository erstellen.
2. Alle Dateien und Ordner aus diesem ZIP hochladen.
3. Darauf achten, dass `app`, `public`, `package.json` und `.gitignore` direkt im Hauptverzeichnis liegen.

## Vercel

1. In Vercel `Add New` → `Project` wählen.
2. Das neue GitHub-Repository auswählen.
3. Framework: Next.js.
4. `Deploy` drücken.

Das Logo liegt unter `public/arpetal-reisen-logo.png`.
